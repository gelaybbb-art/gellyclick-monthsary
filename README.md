# GellyClick — Our Little Forever ♡

A responsive romantic monthsary greeting website with a soft editorial design, six photo gallery images, love notes, an interactive letter popup, and a virtual hug button.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `gellyclick-monthsary`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to finish publishing.

Expected URL: `https://YOUR-USERNAME.github.io/gellyclick-monthsary/`

For the GellyClick account `gelaybbb-art`, the expected URL is:
`https://gelaybbb-art.github.io/gellyclick-monthsary/`

## Personalize before sharing
- Replace sample gallery images in `index.html` with your own couple photos (or images you have permission to use).
- Edit the letter and wording in the HTML to add the couple's names, monthsary date, and personal memories.
- The images currently use Unsplash URLs, and Google Fonts require an internet connection.
- This is a static site: no backend, API key, countdown, or background music is needed.
